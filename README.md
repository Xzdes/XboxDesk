# XboxDesk

[![Platform](https://img.shields.io/badge/platform-Windows%2010%2B-0078D6?logo=windows)](https://github.com/)
[![Language](https://img.shields.io/badge/language-Rust-orange?logo=rust)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**XboxDesk — геймпад Xbox как клавиатура и мышь.**

Нативное Windows-приложение с современным dark gaming UI: курсор с точкой и круговым фокусом, живой визуализацией контроллера и удобным редактором привязок.

Программа превращает геймпад Xbox (XInput) в обычную
клавиатуру и мышь: любая кнопка, стик, крестовина или триггер может нажимать
клавиши, вводить текст, кликать мышью, крутить колесо и выполнять макросы.
Все привязки настраиваются в собственном графическом интерфейсе — кнопки
геймпада и комбинации клавиатуры захватываются одним нажатием.

Сделана по образцу `alibi-quic`: рукописный нативный Win32-интерфейс на
`windows-sys`, без сторонних зависимостей, один переносимый `.exe` со
статической CRT, собственной иконкой и манифестом (современные общие
контролы, PerMonitorV2 DPI). Интерфейс и журнал — на русском.

## Запуск и остановка

Программа **без терминала**: обычный GUI-`exe`, запускается двойным кликом,
ничего лишнего на экране не держит.

```powershell
cargo build --release
.\target\release\XboxDesk.exe   # или двойной клик по файлу
```

- Закрытие главного окна полностью останавливает процесс (код возврата 0):
  движок перед выходом отпускает все зажатые клавиши и кнопки мыши.
- Завершение сеанса/выключение Windows закрывает окно штатным `WM_CLOSE` —
  тот же путь остановки.
- Единственный `.exe` (≈525 КБ) не требует установки: CRT вшита статически,
  из внешнего — только системные DLL Windows (`user32`, `gdi32`, `kernel32`,
  `comctl32`) и `xinput1_4/1_3/9_1_0.dll`, которая загружается в рантайме
  с откатом к более старым версиям.
- Иконка приложения и манифест вшиты в exe штатным `rc.exe` из Windows SDK
  (см. `build.rs`); иконка показывается в заголовке окна, на панели задач
  и у самого файла в проводнике.

## Окно программы

- **Шапка** — бренд с акцентной планкой, путь к настройкам, статус-пилюля
  (подключение геймпада, заряд, состояние движка), кнопки «Запустить» /
  «Остановить» и «Настройки…».
- **Геймпад** — живая схема контроллера: кнопки подсвечиваются при нажатии
  (ABXY — цветным гало в цветах Xbox), стики показывают отклонение и мертвую
  зону, триггеры — полоски-индикаторы, guide-кнопка светится при подключении,
  в шапке карточки — иконка батареи с процентом и цветом уровня.
- **Привязки** — список сопоставлений: цветная фишка кнопки (ABXY в цветах
  Xbox, остальное в слейтовых тонах), «событие → действие», янтарная отметка
  «вибро». Кнопки «Назначить…», «Изменить…» (или двойной клик), «Удалить»,
  «Сбросить на стандартные» (в настройках).
- **Журнал** — события движка с временем: подключения, старт/стоп,
  предупреждения разбора настроек.

Карточки нарисованы с мягкой тенью и акцентными заголовками секций, весь
интерфейс масштабируется по DPI (PerMonitorV2).

### Редактор привязки

1. **Кнопка геймпада** — «Нажать…» и нажать любую кнопку/крестовину/стик/
   триггер на контроллере (движок на время захвата перестает выполнять
   привязки и дает вибрацией понять, что кнопка поймана).
2. **Событие** — когда срабатывать: нажатие, отпускание, удержание N мс,
   двойное нажатие (окно N мс), повтор (сразу и каждые N мс).
3. **Действие**:
   - клавиши/комбинация (`CTRL+SHIFT+T`, `WIN+D`, `F5`, `VOLUME_UP`…) —
     можно ввести текстом или захватить с клавиатуры кнопкой «С клавиатуры»
     (Enter — готово, Esc — отмена);
   - ввод текста — печатается посимвольно через `KEYEVENTF_UNICODE`,
     раскладка не важна;
   - клик мыши — ЛКМ/ПКМ/СКМ/боковые X1–X2;
   - колесо прокрутки (вертикальное или горизонтальное), деления со знаком;
   - макрос — шаги через `;`: `keys:CTRL+A;delay:200;text:привет;keys:ENTER`.
4. **Вибрация при срабатывании** — короткий импульс (90 мс) как подтверждение.

### Настройки

- Режим левого и правого стика: **мышь** (курсор с круговой мертвой зоной и
  квадратичной кривой разгона), **стрелки**, **WASD** (удержание клавиш),
  **выключен**; чувствительность 1–30 для каждого.
- Триггеры LT/RT крутят колесо прокрутки, скорость 1–10.
- Мертвая зона стиков 0–40 %.
- Вибрация — мастер-выключатель; автозапуск движка вместе с программой.
- Сброс всех привязок на стандартный набор (с подтверждением).

## Стандартная раскладка

Игровые привычки, переложенные на действия Windows: A — подтвердить, B —
контекстное меню, Y — отмена, бамперы — переключение как смена снаряжения,
RB — «карта» (представление задач), Back — «выход в меню» (рабочий стол),
Start — ввод, крестовина — громкость и медиа, L3 — пауза, R3 — TAB,
долгие триггеры — блокировка и снимок экрана (короткое нажатие — колесо).

| Кнопка | Событие | Действие |
|---|---|---|
| A | нажатие | клик ЛКМ (подтвердить) |
| B | нажатие | клик ПКМ (контекстное меню) |
| X | нажатие | клик СКМ |
| Y | нажатие | ESC (отмена) |
| LB | нажатие | ALT+TAB (переключение окон) |
| RB | нажатие | WIN+TAB (представление задач) |
| Back | нажатие | WIN+D (показать рабочий стол) |
| Start | нажатие | ENTER |
| Крестовина вверх/вниз | повтор 150 мс | VOLUME_UP / VOLUME_DOWN |
| Крестовина влево/вправо | нажатие | MEDIA_PREV / MEDIA_NEXT |
| L3 (левый стик) | нажатие | MEDIA_PLAY_PAUSE (пауза) |
| R3 (правый стик) | нажатие | TAB (переход по элементам) |
| LT | удержание 800 мс | WIN+L (блокировка) |
| RT | удержание 800 мс | PRINTSCREEN (снимок экрана) |

Стики по умолчанию: левый — мышь (14), правый — стрелки (10); LT/RT — колесо.

## Файл настроек

`%APPDATA%\XboxDesk\settings.ini` (UTF-8), создается при первом запуске.
Можно править вручную **при закрытой программе**. Формат:

```ini
[settings]
left_stick=mouse        ; mouse | arrows | wasd | off
left_sensitivity=14     ; 1..30
right_stick=arrows
right_sensitivity=10
trigger_scroll=1        ; 1/0
scroll_speed=4          ; 1..10
deadzone=15             ; 0..40, %
rumble=1                ; 1/0 — мастер-выключатель вибрации
auto_start=1            ; 1/0 — запускать движок вместе с программой

[bindings]
# строка = КНОПКА=событие|действие[|rumble]
A=press|mouse:left
DPadUp=repeat:150|keys:VOLUME_UP
LT=hold:800|keys:WIN+L|rumble
Y=press|macro:keys:CTRL+A;delay:150;text:Привет
```

Кнопки: `A B X Y LB RB Back Start DPadUp DPadDown DPadLeft DPadRight LThumb
RThumb LT RT`. События: `press`, `release`, `hold:мс`, `double:мс`,
`repeat:мс`. Действия: `keys:КОМБО`, `text:ТЕКСТ`,
`mouse:left|right|middle|x1|x2`, `wheel:N`, `wheelh:N`, `macro:…`.
Испорченные строки не роняют программу — пропускаются с предупреждением
в журнале.

## Сборка и тесты

```powershell
cargo build --release   # target\release\XboxDesk.exe (иконка + манифест)
cargo test              # 24 модульных теста: парсеры, конечный автомат
                        # событий, мертвая зона, round-trip конфига
```

Требуется только Rust (MSVC toolchain); `windows-sys` — единственная
зависимость, и та лишь на время сборки (чистый FFI). Иконка `assets/xboxdesk.ico`
генерируется скриптом `assets/make_icon.py` (Pillow) и вместе с манифестом
`assets/xboxdesk.manifest` компилируется в exe скриптом `build.rs` через
`rc.exe` из Windows SDK; если SDK нет — exe соберется без иконки.

## Важные замечания

- **Окна от имени администратора**: Windows блокирует ввод из менее
  привилегированного процесса (UIPI). Чтобы управлять приложением, запущенным
  от администратора, запускайте XboxDesk тоже от администратора.
- **Игры с античитом**: эмуляция ввода может распознаваться античитами как
  подозрительная. Используйте в играх на свой страх и риск.
- **Безопасность клавиш**: инжектор ведет список нажатых клавиш и при любой
  остановке (закрытие окна, завершение сеанса) отпускает всё зажатое —
  «залипших» клавиш не остается.
- Привязки применяются движком на лету: после сохранения списка окно настроек
  поднимает версию конфига, движок сбрасывает состояния событий и отпускает
  клавиши.

## Устройство кода

| Модуль | Назначение |
|---|---|
| `main.rs` | входная точка без консоли: конфиг → движок → окно → остановка |
| `gui.rs` | главное окно: схема геймпада, список привязок, журнал |
| `dialog.rs` | модальные редакторы привязки и настроек, захват ввода |
| `engine.rs` | поток 125 Гц: опрос XInput, конечный автомат событий, стики→мышь/клавиши |
| `send.rs` | `SendInput`: клавиши, текст, мышь, колесо; учет зажатого |
| `binding.rs` | модель привязки: кнопка, событие, действие, макрос |
| `config.rs` | INI в `%APPDATA%\XboxDesk`, чтение/запись с предупреждениями |
| `vk.rs` | виртуальные коды клавиш ↔ имена, парсер комбинаций |
| `xinput.rs` | ручной FFI XInput с загрузкой DLL в рантайме |
| `ui.rs` | палитра, шрифты, GDI-примитивы, карточки с тенью, owner-draw кнопки |
| `build.rs` | компиляция иконки и манифеста штатным `rc.exe` |

GUI и движок общаются через `Arc<Mutex<Shared>>`: GUI кладет команды
(запуск/остановка, новая конфигурация, режим захвата кнопки), движок кладет
состояние геймпада и строки журнала. Мьютекс никогда не удерживается во время
открытия диалогов и сохранения файла.
